## 🚀 Featured public work

### 🎙️ [OpenWhispr contribution](https://github.com/OpenWhispr/openwhispr/pull/3330) — Clear feedback when a local model falls back to CPU

OpenWhispr can keep a local model running on CPU after Vulkan runs out of GPU memory. My open pull request adds a notification and persistent warning so users can see why generation slowed down and which backend is active. It includes focused tests and manual reproductions with two model sizes.

`Open source · Desktop UX · Local LLMs`

### 🎬 [Video Upload AI](https://github.com/Erick-Alen/video-uploader-ai) — From video transcript to publishing ideas

A Rocketseat NLW prototype designed to turn an MP4 into YouTube title and description suggestions. Its React interface extracts audio in the browser with FFmpeg; a Fastify API accepts the audio, requests transcription, and streams generated text from prompt templates. The repository exposes the browser flow, API routes, SQLite models, and OpenAI integration. It is a learning prototype, not a deployed product.

`React · TypeScript · Fastify · FFmpeg · Prisma · OpenAI API`

### 🐍 [Fast Zero](https://github.com/Erick-Alen/fast_zero) — A FastAPI learning project with tests

A tutorial-based API for user accounts and personal to-dos. It covers password hashing, token authentication, user-scoped task queries, SQLAlchemy models, Alembic migrations, and PostgreSQL. The repository also includes tests, linting, Docker configuration, and a CI workflow.

`Python · FastAPI · SQLAlchemy · PostgreSQL · Pytest`

### 🎟️ [NLW Unite / pass.in](https://github.com/Erick-Alen/nlw-unite-devops) — Event registration and check-in

Built during Rocketseat's NLW Unite, this API creates events and manages attendees while enforcing unique registration and capacity limits. Participants can retrieve a badge and check in once. The repository includes Swagger documentation, container configuration, and Kubernetes/Helm deployment files.

`TypeScript · Fastify · Prisma · SQLite · Docker · Helm`

### 👥 [My Contacts](https://github.com/Erick-Alen/my-contacts) — A searchable personal address book

A JStack course project with a React interface for adding, editing, searching, sorting, and deleting contacts. An Express API stores contacts and categories in PostgreSQL; the interface handles loading, empty, and error states.

`React · JavaScript · Express · PostgreSQL`

### 💸 [Fincheck](https://github.com/Erick-Alen/Fincheck) — Accounts and transactions in one dashboard

A JStack course project for tracking bank accounts, income, expenses, and transaction categories. It combines a React dashboard with a NestJS API, authentication, Prisma models, and PostgreSQL storage.

`React · TypeScript · NestJS · Prisma · PostgreSQL`
